= Configura una connessione tra Workflow Automation e Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi configurare una connessione sicura tra OnCommand Workflow Automation (WFA) e Unified Manager. La connessione a Workflow Automation ti consente di utilizzare funzionalità di protezione come i flussi di lavoro di configurazione di SnapMirror e SnapVault, nonché i comandi per gestire le relazioni di SnapMirror.

.Prima di iniziare
* La versione installata di Workflow Automation deve essere 5.1.1P6 o successiva.
+
[NOTE]
====
Il "pacchetto WFA per la gestione di Clustered Data ONTAP" è incluso in WFA 5.1.1P6, quindi non è necessario scaricare questo pacchetto dallo NetAppStorage Automation Store e installarlo separatamente sul server WFA come richiesto in passato. https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["Download WFA"^]

====
* Devi disporre del nome dell'utente del database che hai creato in Unified Manager per supportare le connessioni tra WFA e Unified Manager.
+
A questo utente del database deve essere stato assegnato il ruolo utente Integration Schema.

* Devi avere il ruolo di Administrator o di Architect in Workflow Automation.
* Devi disporre dell'indirizzo host, del numero di porta 443, del nome utente e della password per la configurazione di Workflow Automation.
* Devi disporre del ruolo di Amministratore dell'applicazione o di Amministratore dello storage.


.Passaggi
. Nel riquadro di navigazione a sinistra, fai clic su *Generale* > *Workflow Automation*.
. Nell'area *Database User* della pagina *Workflow Automation*, seleziona il nome e inserisci la password dell'utente del database che hai creato per supportare le connessioni di Unified Manager e Workflow Automation.
. Nell'area *Workflow Automation Credentials* della pagina, immetti l'host name o l'indirizzo IP (IPv4 o IPv6), il nome utente e la password per la configurazione di Workflow Automation.
+
Devi utilizzare la porta del server Unified Manager (porta 443).

. Fare clic su *Save*.
. Se utilizzi un certificato autofirmato, fai clic su *Sì* per autorizzare il certificato di sicurezza.
+
Viene visualizzata la pagina Workflow Automation.

. Fai clic su *Sì* per ricaricare l'interfaccia utente web e aggiungere le funzionalità di Workflow Automation.
