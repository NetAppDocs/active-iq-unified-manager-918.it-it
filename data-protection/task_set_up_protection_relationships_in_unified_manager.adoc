= Configura le relazioni di protezione in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per utilizzare Unified Manager e OnCommand Workflow Automation per configurare relazioni di SnapMirror e SnapVault per proteggere i tuoi dati, devi eseguire diversi passaggi.

.Prima di iniziare
* Devi disporre del ruolo di Amministratore dell'applicazione o di Amministratore dello storage.
* Devi aver stabilito relazioni peer tra due cluster o due macchine virtuali di storage (SVM).
* OnCommand Workflow Automation deve essere integrato con Unified Manager:
+
** link:task_configure_connection_between_workflow_automation_um.html["Configura OnCommand Workflow Automation"].
** link:task_verify_um_data_source_caching_in_workflow_automation.html["Verifica della memorizzazione nella cache dell'origine dati di Unified Manager in Workflow Automation"].




.Passaggi
. A seconda del tipo di relazione di protezione che vuoi creare, procedi in uno dei seguenti modi:
+
** link:task_create_snapmirror_relationship_from_health_volume.html["Crea una relazione di protezione di SnapMirror"].
** link:task_create_snapvault_protection_relationship_from_health_volume_details.html["Crea una relazione di protezione di SnapVault"].


. Se vuoi creare una policy per la relazione, a seconda del tipo di relazione che stai creando, procedi in uno dei seguenti modi:
+
** link:task_create_snapvault_policy_to_maximize_transfer_efficiency.html["Crea un criterio SnapVault"].
** link:task_create_snapmirror_policy_to_maximize_transfer_efficiency.html["Crea una policy SnapMirror"].


. link:task_create_snapmirror_and_snapvault_schedules.html["Crea una pianificazione di SnapMirror o SnapVault"].
