= Scopri gli eventi delle Storage VM in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi relativi alle macchine virtuali di archiviazione (Storage Virtual Machine, note anche come SVM) ti forniscono informazioni sullo stato delle tue storage VM (SVM) in modo che tu possa monitorare eventuali problemi. Gli eventi sono raggruppati per area di impatto e includono il nome dell'evento e della trap, il livello di impatto, il tipo di origine e la gravità.

Un asterisco (*) identifica gli eventi EMS che sono stati convertiti in eventi di Unified Manager.
