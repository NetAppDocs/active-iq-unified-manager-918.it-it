= Scopri gli eventi relativi agli involucri in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi relativi agli alloggiamenti ti forniscono informazioni sullo stato degli alloggiamenti per dischi nel tuo data center, consentendoti di monitorare potenziali problemi. Gli eventi sono raggruppati per area di impatto e includono il nome dell'evento e della trap, il livello di impatto, il tipo di origine e la gravità.
