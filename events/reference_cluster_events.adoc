= Scopri gli eventi cluster in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi del cluster forniscono informazioni sullo stato dei cluster, consentendoti di monitorarli per individuare potenziali problemi. Gli eventi sono raggruppati per area di impatto e includono il nome dell'evento, il nome della trap, il livello di impatto, il tipo di origine e la gravità.
