= Scopri gli eventi Snapshot in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi Snapshot forniscono informazioni sullo stato degli snapshot, consentendoti di monitorarli per individuare potenziali problemi. Gli eventi sono raggruppati per area di impatto e includono il nome dell'evento, il nome della trap, il livello di impatto, il tipo di origine e la gravità.
