= Scopri gli eventi della stazione di gestione in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi della stazione di gestione ti forniscono informazioni sullo stato del server su cui è installato Unified Manager, in modo che tu possa monitorare eventuali problemi. Gli eventi sono raggruppati per area di impatto e includono il nome dell'evento e del trap, il livello di impatto, il tipo di origine e la gravità.

[NOTE]
====
Questi ultimi due eventi di performance erano disponibili solo per Unified Manager 7.2. Se uno di questi eventi esiste nello stato New e poi esegui l'aggiornamento a una versione più recente del software Unified Manager, gli eventi non verranno eliminati automaticamente. Dovrai spostare manualmente gli eventi nello stato Resolved.
