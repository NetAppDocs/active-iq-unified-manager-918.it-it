= Scopri le aree di impatto degli eventi in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi sono suddivisi in sei aree di impatto (disponibilità, capacità, configurazione, prestazioni, protezione e sicurezza) per consentirti di concentrarti sui tipi di eventi di cui sei responsabile.

* *Disponibilità*
+
Gli eventi di disponibilità ti avvisano se un oggetto di storage va offline, se un servizio di protocollo si interrompe, se si verifica un problema con il failover dello storage o se si verifica un problema con l'hardware.

* *Capacità*
+
Gli eventi di capacità ti avvisano se i tuoi aggregati, volumi, LUN o namespace si stanno avvicinando o hanno raggiunto una soglia di dimensione, oppure se il tasso di crescita è insolito per il tuo ambiente.

* *Configurazione*
+
Gli eventi di configurazione ti informano del rilevamento, dell'eliminazione, dell'aggiunta, della rimozione o della ridenominazione dei tuoi oggetti di storage. Gli eventi di configurazione hanno un livello di impatto Event e un tipo di severità Information.

* *Prestazioni*
+
Gli eventi relativi alle prestazioni ti informano sulle condizioni delle risorse, della configurazione o dell'attività del tuo cluster che potrebbero influire negativamente sulla velocità di immissione o recupero dei dati negli oggetti di archiviazione monitorati.

* *Protezione*
+
Gli eventi di protezione ti notificano incidenti o rischi che coinvolgono le relazioni SnapMirror, problemi con la capacità della destinazione, problemi con le relazioni SnapVault o problemi con i processi di protezione. Qualsiasi oggetto ONTAP, in particolare aggregati, volumi e SVM, che ospita volumi secondari e relazioni di protezione è classificato nell'area di impatto della protezione.

* *Sicurezza*
+
Gli eventi di sicurezza ti informano sul livello di sicurezza dei cluster ONTAP, delle macchine virtuali di storage (SVM) e dei volumi in base ai parametri definiti nel https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["NetApp Security Hardening Guide per ONTAP 9"^].

+
Inoltre, quest'area comprende gli eventi di aggiornamento segnalati dalla piattaforma Active IQ.
