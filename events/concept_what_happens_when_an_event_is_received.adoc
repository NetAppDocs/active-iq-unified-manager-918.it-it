= Capisci come Active IQ Unified Manager gestisce un evento ricevuto
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando Unified Manager riceve un evento, questo viene visualizzato nella pagina Dashboard, nella pagina di inventario Event Management, nelle schede Summary ed Explorer della pagina Cluster/Performance e nella pagina di inventario specifica dell'oggetto (ad esempio, la pagina di inventario Volumes/Health).

Quando Unified Manager rileva più occorrenze continue della stessa condizione di evento per lo stesso componente del cluster, le considera tutte come un singolo evento, non come eventi separati. La durata dell'evento viene incrementata per indicare che l'evento è ancora attivo.

A seconda di come configuri le impostazioni nella pagina Alert Setup, puoi notificare questi eventi ad altri utenti. L'avviso avvia le seguenti azioni:

* Puoi inviare un'e-mail relativa all'evento a tutti gli utenti amministratori di Unified Manager.
* L'evento può essere inviato ad altri destinatari via e-mail.
* Puoi inviare una trap SNMP al ricevitore della trap.
* Puoi eseguire uno script personalizzato per compiere un'azione.
