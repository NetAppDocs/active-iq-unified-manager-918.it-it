= Elimina i report programmati in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Una volta programmati i report, puoi eliminarli dalla pagina Programmazione report.

.Prima di iniziare
* Devi disporre del ruolo di Amministratore dell'applicazione o di Amministratore dello storage.


.Passaggi
. Nel riquadro di navigazione a sinistra, fai clic su *Gestione dello storage* > *Pianificazioni report*.
+
image::../media/scheduled_reports_2.gif[Uno screenshot dell'interfaccia utente che mostra i report programmati.]

+
[NOTE]
====
Se disponi delle autorizzazioni appropriate, puoi rimuovere qualsiasi report e la relativa pianificazione dal sistema.

====
. Fai clic sull'icona Altro image:../media/more_icon.gif[""] per la pianificazione che desideri rimuovere.
. Fai clic su *Delete*.
. Conferma la tua decisione.
+
Il report programmato viene rimosso dall'elenco e non verrà più generato né distribuito in base alla pianificazione impostata.

+
[NOTE]
====
Se elimini una visualizzazione personalizzata dalla pagina dell'inventario, verranno eliminati anche tutti i file Excel personalizzati o i report pianificati che usano quella visualizzazione.

====
