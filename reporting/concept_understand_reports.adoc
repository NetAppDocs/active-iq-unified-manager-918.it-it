= Capisci i report in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
I report mostrano informazioni dettagliate su storage, rete, qualità del servizio e relazioni di protezione, aiutandoti a identificare e risolvere potenziali problemi prima che si verifichino.

Quando personalizzi una vista, puoi salvarla con un nome univoco per un utilizzo futuro. Puoi pianificare un report basato su quella vista perché venga eseguito regolarmente e condividerlo con altri. Puoi anche scaricare la vista in Excel per personalizzarla usando le funzionalità avanzate di Excel, quindi caricare di nuovo quel file in Unified Manager . Se pianifichi un report usando quella vista, userà il file Excel che hai caricato per creare report completi che puoi condividere.

Puoi gestire tutti i report programmati dalla pagina "Programmazione report".

[NOTE]
====
Devi avere il ruolo Application Administrator o Storage Administrator per gestire i report.

====
Puoi scaricare i report come file CSV (valori separati da virgola), Excel o PDF.
