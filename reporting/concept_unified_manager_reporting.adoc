= Scopri la creazione di report in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager (precedentemente OnCommand Unified Manager) offre la possibilità di visualizzare, personalizzare, scaricare e pianificare report per i tuoi sistemi storage ONTAP. I report possono fornire dettagli sulla capacità del sistema storage, sullo stato di salute, sulle prestazioni, sulla sicurezza e sulle relazioni di protezione.

La nuova funzionalità di reporting e pianificazione di Unified Manager introdotta in Active IQ Unified Manager 9.6 sostituisce il precedente motore di reporting ritirato nella versione 9.5 di Unified Manager.

La funzionalità di reporting ti offre diverse visualizzazioni della rete, fornendoti informazioni utili su capacità, stato di salute, prestazioni, sicurezza e dati di protezione. Puoi personalizzare le visualizzazioni mostrando, nascondendo e riorganizzando le colonne, filtrando i dati, ordinando i dati e cercando nei risultati. Puoi salvare le visualizzazioni personalizzate per riutilizzarle, scaricarle come report e pianificarle come report ricorrenti da distribuire tramite email.

Puoi scaricare le visualizzazioni in formato Microsoft® Excel e personalizzarle. Puoi usare funzionalità avanzate di Excel, come ordinamenti complessi, filtri a più livelli, tabelle pivot e grafici. Quando sei soddisfatto del report Excel risultante, puoi caricare il file Excel per usarlo ogni volta che il report viene pianificato e condiviso.

Oltre a generare report dall'interfaccia utente, puoi estrarre dati relativi a integrità, sicurezza e prestazioni da Unified Manager utilizzando questi metodi aggiuntivi:

* Utilizzo di Open Database Connectivity (ODBC) e degli strumenti ODBC per accedere direttamente al database e ottenere informazioni sul cluster
* Esecuzione delle API REST di Unified Manager per restituire le informazioni che ti interessa esaminare


A partire da questa versione di Active IQ Unified Manager, sono stati apportati i seguenti miglioramenti ai report:

* Ricevi un'e-mail per un report in base alla pianificazione configurata. Anche quando generi un report su richiesta, riceverai un'e-mail.
* Il nome del file del report e i metadati del report includono l'hostname da cui è stato generato il report. Grazie a questo miglioramento, anche se qualcuno modifica il nome del file, puoi comunque identificare l'hostname da cui è stato generato il report.
