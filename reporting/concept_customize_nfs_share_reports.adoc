= Personalizza i report delle condivisioni NFS in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi personalizzare i report delle condivisioni NFS per analizzare le informazioni sulle policy di esportazione NFS e sulle regole per i volumi nei tuoi sistemi di storage. Ad esempio, puoi personalizzare i report per visualizzare i volumi con percorsi di montaggio inaccessibili e i volumi con la policy di esportazione predefinita.
