= Rimuovi l'utente umadmin personalizzato e il gruppo di manutenzione per Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se hai creato una home directory personalizzata per definire il tuo utente umadmin e l'account di manutenzione prima di installare Unified Manager, dovresti rimuovere questi elementi dopo aver disinstallato Unified Manager.

La disinstallazione standard di Unified Manager non rimuove l'utente umadmin e l'account di manutenzione definiti dall'utente. Devi eliminare manualmente questi elementi.

.Passaggi
. Accedi al server Red Hat Enterprise Linux come utente root.
. Elimina l'utente umadmin:
+
`userdel umadmin`

. Elimina il gruppo di manutenzione:
+
`groupdel maintenance`
