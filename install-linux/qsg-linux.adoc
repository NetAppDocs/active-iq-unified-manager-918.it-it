= Inizia a usare Active IQ Unified Manager su Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi scaricare il pacchetto di installazione e installare Unified Manager su una piattaforma Red Hat Enterprise Linux fisica o virtuale.



[[system-requirements]]
== Requisiti di sistema

* Sistema operativo: Red Hat Enterprise Linux versioni 8.x e 9.4, basate su architettura x86_64, installate utilizzando l'ambiente base "Server with GUI" dall'opzione *Software Selection* del programma di installazione del sistema operativo
* RAM: 12 GB, CPU: 9572 MHz totali
* Spazio libero su disco: 100 GB di spazio su disco nella directory  `/opt/netapp/data`, 50 GB nella partizione root. Per le directory  `/opt` e  `/var/log` montate separatamente, assicurati che  `/opt` abbia 15 GB,  `/var/log` abbia 16 GB e  `/tmp` abbia 10 GB di spazio libero.


Per i requisiti di sistema dettagliati e per informazioni sull'installazione del prodotto in un sito protetto, consulta link:../install-linux/concept_requirements_for_install_unified_manager.html["Requisiti per l'installazione di Unified Manager"] e link:http://mysupport.netapp.com/matrix["Matrice di interoperabilità"].



[[install-active-iq-unified-manager]]
== Installa Active IQ Unified Manager



[[download-the-installer]]
=== Scarica il programma di installazione

. Scarica il `ActiveIQUnifiedManager-<version>.zip` pacchetto di installazione insieme al certificato di firma del codice (`.pem`) e alla firma digitale (`.sig`).
. Nella directory in cui hai scaricato il file di installazione, esegui:
+
`# unzip ActiveIQUnifiedManager-<version>.zip`





[[verify-integrity]]
=== Verifica l'integrità

Esegui i seguenti comandi per verificare l'integrità del pacchetto di installazione:

* Esegui `openssl x509 -pubkey -noout -in AIQUM-RHEL-CLIENT-INTER-ROOT.pem > <public_key_file_name>` per creare un file con la chiave pubblica del certificato di firma del codice.
* Esegui `openssl dgst -sha256 -verify <public_key_file_name> -signature <signature_file_name> ActiveIQUnifiedManager-<version>.zip` per verificare la firma del pacchetto di installazione.




[[verify-repository-configuration]]
=== Verifica la configurazione del repository

La procedura per configurare un repository Red Hat Enterprise Linux è specifica per ogni sito. Puoi utilizzare lo `pre_install_check.sh` script incluso nel pacchetto di installazione per verificare la configurazione del tuo sistema operativo. Se il tuo sistema è connesso a Internet, ricevi automaticamente le istruzioni per configurare il repository Red Hat Enterprise Linux.

`# sudo ./pre_install_check.sh`



[[install-unified-manager]]
=== Installa Unified Manager

Unified Manager utilizza l' `yum`utility per installare il software e qualsiasi software dipendente. Poiché esistono diverse immagini di Red Hat Enterprise Linux, i pacchetti installati dipendono dal software presente nelle immagini. L' `yum`utility determina i pacchetti software dipendenti da installare. Se hai bisogno di ulteriori informazioni sui pacchetti software dipendenti, consulta link:../install-linux/reference_red_hat_software_and_installation_requirements.html["Requisiti software e di installazione per Linux"].

Per installare Unified Manager, esegui il comando seguente come utente root o utilizzando `sudo`, dalla directory in cui hai estratto il file di installazione:

`# yum install netapp-um<version>.x86_64.rpm`

o

`% sudo yum install netapp-um<version>.x86_64.rpm`

Al termine dell'installazione, vengono visualizzate le informazioni per connetterti all'interfaccia utente web di Unified Manager. Se non riesci a connetterti all'interfaccia utente web, consulta il  `README`file incluso nel software per ulteriori informazioni sulle restrizioni della porta 443.
