= Aggiorna i prodotti di terze parti dopo l'installazione di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi aggiornare prodotti di terze parti, come JRE, quando Unified Manager è già installato sui sistemi Linux.

Le aziende che sviluppano questi prodotti di terze parti segnalano regolarmente le vulnerabilità di sicurezza. Puoi aggiornare il software alle versioni più recenti secondo le tue esigenze.
