= Cambia la password di JBoss in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi reimpostare la password specifica dell'istanza di JBoss impostata durante l'installazione. Puoi reimpostare la password facoltativamente, se il tuo sito richiede questa funzionalità di sicurezza per sovrascrivere l'impostazione di installazione di Unified Manager. Questa operazione modifica anche la password che JBoss utilizza per accedere a MySQL.

* Devi disporre dell'accesso come utente root al sistema Red Hat Enterprise Linux su cui è installato Unified Manager.
* Devi poter accedere allo script fornito da NetApp `password.sh` nella directory `/opt/netapp/essentials/bin`.


.Passaggi
. Accedi al sistema come utente root.
. Arresta i servizi di Unified Manager immettendo i seguenti comandi nell'ordine indicato:
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
Non arrestare il software MySQL associato.

. Inserisci il seguente comando per avviare la procedura di modifica della password:
+
`/opt/netapp/essentials/bin/password.sh resetJBossPassword`

. Quando richiesto, inserisci la nuova password di JBoss e poi inseriscila una seconda volta per confermarla.
+
Tieni presente che la password deve essere compresa tra 8 e 16 caratteri e deve contenere almeno una cifra, una lettera maiuscola e una minuscola, e almeno uno di questi caratteri speciali:

+
`+!@%^*-_+=[]:<>.?/~+`

. Al termine dell'esecuzione dello script, avvia i servizi di Unified Manager immettendo i seguenti comandi nell'ordine indicato:
+
`systemctl start ocie`

+
`systemctl start ocieau`

. Dopo aver avviato tutti i servizi, puoi accedere all'interfaccia utente di Unified Manager.
