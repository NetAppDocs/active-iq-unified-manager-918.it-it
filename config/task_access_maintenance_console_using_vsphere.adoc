= Accedi alla console di manutenzione usando la console VM vSphere in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se l'interfaccia utente di Unified Manager non è operativa, oppure se devi eseguire funzioni non disponibili nell'interfaccia utente, puoi accedere alla console di manutenzione per riconfigurare la tua appliance virtuale.

.Prima di iniziare
* Devi essere l'utente di manutenzione.
* L'appliance virtuale deve essere accesa per accedere alla console di manutenzione.


.Passaggi
. In vSphere Client, individua l'appliance virtuale Unified Manager.
. Fai clic sulla scheda *Console*.
. Fai clic all'interno della finestra della console per accedere.
. Accedi alla console di manutenzione utilizzando il tuo nome utente e la tua password.
+
Dopo 15 minuti di inattività, la console di manutenzione ti disconnette.
