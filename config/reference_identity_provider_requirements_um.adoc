= Usa un provider di identità in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando configuri Unified Manager per utilizzare un provider di identità (IdP) per eseguire l'autenticazione SAML per tutti gli utenti remoti, devi tenere presenti alcune impostazioni di configurazione obbligatorie affinché la connessione a Unified Manager abbia esito positivo.

Devi inserire l'URI e i metadati di Unified Manager nel server IdP. Puoi copiare queste informazioni dalla pagina di autenticazione SAML di Unified Manager. Unified Manager è considerato il service provider (SP) nello standard Security Assertion Markup Language (SAML).



[[supported-encryption-standards]]
== Standard di crittografia supportati

* Advanced Encryption Standard (AES): AES-128 e AES-256
* Algoritmo di hash sicuro (SHA): SHA-1 e SHA-256




[[validated-identity-providers]]
== Fornitori di identità validati

* Shibboleth
* Active Directory Federation Services (ADFS)




[[adfs-configuration-requirements]]
== Requisiti di configurazione di ADFS

* Devi definire tre regole di attestazione nel seguente ordine, necessarie affinché Unified Manager possa analizzare le risposte SAML di ADFS per questa voce di trust della relying party.
+
[cols="2*"]
|===
| Regola attestazioni | Valore 


 a| 
SAM-account-name
 a| 
ID nome



 a| 
SAM-account-name
 a| 
urn:oid:0.9.2342.19200300.100.1.1



 a| 
Gruppi di token -- Nome non qualificato
 a| 
urn:oid:1.3.6.1.4.1.5923.1.5.1.1

|===
* Devi impostare il metodo di autenticazione su "`Forms Authentication`", altrimenti gli utenti potrebbero ricevere un errore quando escono da Unified Manager. Segui questi passaggi:
+
.. Apri la console di gestione ADFS.
.. Fai clic sulla cartella Criteri di autenticazione nella visualizzazione ad albero a sinistra.
.. In Azioni sulla destra, fai clic su Modifica criterio di autenticazione primaria globale.
.. Imposta il metodo di autenticazione Intranet su "`Forms Authentication`" invece dell'impostazione predefinita "`Windows Authentication`".


* In alcuni casi l'accesso tramite l'IdP viene rifiutato quando il certificato di sicurezza di Unified Manager è firmato da una CA. Esistono due soluzioni alternative per risolvere questo problema:
+
** Segui le istruzioni indicate nel link per disabilitare il controllo di revoca sul server ADFS per la relying party associata al certificato CA nella catena:
+
http://www.torivar.com/2016/03/22/adfs-3-0-disable-revocation-check-windows-2012-r2/["Disabilita il controllo della revoca per Relying Party Trust"]

** Assicurati che il server CA risieda all'interno del server ADFS per firmare la richiesta di certificato del server Unified Manager.






[[other-configuration-requirements]]
== Altri requisiti di configurazione

* Lo scostamento dell'orologio di Unified Manager è impostato su 5 minuti, quindi la differenza di orario tra il server IdP e il server Unified Manager non può essere superiore a 5 minuti, altrimenti l'autenticazione non riuscirà.
