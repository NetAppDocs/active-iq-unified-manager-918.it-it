= Cambia la password dell'utente locale in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi modificare la password di accesso dell'utente locale per prevenire potenziali rischi per la sicurezza.

.Prima di iniziare
Devi aver effettuato l'accesso come utente locale.

Le password dell'utente di manutenzione e degli utenti remoti non possono essere modificate seguendo questi passaggi. Per modificare la password di un utente remoto, contatta l'amministratore delle password. Per modificare la password dell'utente di manutenzione, consulta link:task_use_maintenance_console.html["Utilizzo della console di manutenzione"].

.Passaggi
. Accedi a Unified Manager.
. Dalla barra dei menu in alto, fai clic sull'icona dell'utente e poi su *Cambia password*.
+
L'opzione *Cambia password* non compare se sei un utente remoto.

. Nella finestra di dialogo Cambia password, immetti la password corrente e la nuova password.
. Fare clic su *Save*.


Se Unified Manager è configurato in una configurazione ad alta disponibilità, devi modificare la password sul secondo nodo della configurazione. Entrambe le istanze devono avere la stessa password.
