= Verifica la configurazione dei server di autenticazione in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi convalidare la configurazione dei server di autenticazione per assicurarti che il server di gestione sia in grado di comunicare con essi. Puoi convalidare la configurazione cercando un utente o un gruppo remoto nei tuoi server di autenticazione e autenticandoli utilizzando le impostazioni configurate.

.Prima di iniziare
* Devi aver abilitato l'autenticazione remota e configurato il servizio di autenticazione in modo che il server Unified Manager possa autenticare l'utente remoto o il gruppo remoto.
* Devi aver aggiunto i server di autenticazione affinché il server di gestione possa cercare l'utente remoto o il gruppo remoto su questi server e autenticarli.
* Devi avere il ruolo di Amministratore dell'applicazione.


Se il servizio di autenticazione è impostato su Active Directory e stai convalidando l'autenticazione di utenti remoti che appartengono al gruppo principale del server di autenticazione, le informazioni sul gruppo principale non vengono visualizzate nei risultati dell'autenticazione.

.Passaggi
. Nel riquadro di navigazione a sinistra, fai clic su *Generale* > *Autenticazione remota*.
. Fai clic su *Test Authentication*.
. Nella finestra di dialogo Test User, specifica il nome utente e la password dell'utente remoto o il nome utente del gruppo remoto, quindi fai clic su *Test*.
+
Se stai autenticando un gruppo remoto, non devi inserire la password.
