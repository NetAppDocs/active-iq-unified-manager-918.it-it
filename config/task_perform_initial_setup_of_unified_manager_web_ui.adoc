= Esegui la configurazione iniziale dell'interfaccia utente web di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per utilizzare Unified Manager, devi prima configurare le opzioni di configurazione iniziale, tra cui il server NTP, l'indirizzo email dell'utente di manutenzione, l'host del server SMTP e l'aggiunta dei cluster ONTAP.

.Prima di iniziare
Devi aver eseguito le seguenti operazioni:

* Avviata l'interfaccia utente web di Unified Manager utilizzando l'URL fornito dopo l'installazione
* Hai effettuato l'accesso utilizzando il nome utente e la password di manutenzione (utente umadmin per le installazioni Linux) creati durante l'installazione


La pagina Getting Started di Active IQ Unified ManagerGetting viene visualizzata solo quando accedi per la prima volta all'interfaccia utente web. La pagina seguente proviene da un'installazione su VMware.

image::../media/first_experience_wizard.JPG[Uno screenshot che mostra una pagina dell'installazione su VMware.]

Se vuoi modificare una di queste opzioni in seguito, puoi selezionare la tua scelta dalle opzioni generali nel riquadro di navigazione sinistro di Unified Manager. Tieni presente che l'impostazione NTP è valida solo per le installazioni VMware e può essere modificata in seguito tramite la console di manutenzione di Unified Manager.

.Passaggi
. Nella pagina Initial Setup di Active IQ Unified Manager, inserisci l'indirizzo email dell'utente di manutenzione, l'host name del server SMTP ed eventuali opzioni SMTP aggiuntive, nonché il server NTP (solo per le installazioni VMware). Quindi fai clic su *Continue*.
+
[NOTE]
====
Se hai selezionato l'opzione *Usa STARTTLS* o *Usa SSL*, dopo aver cliccato sul pulsante *Continua* verrà visualizzata una pagina relativa al certificato. Verifica i dettagli del certificato e accettalo per proseguire con le impostazioni di configurazione iniziali dell'interfaccia web.

====
. Nella pagina AutoSupport, fai clic su *Accetta e continua* per abilitare l'invio di messaggi AutoSupport da Unified Manager a NetAppActive IQ.
+
Se devi designare un proxy per fornire l'accesso a Internet e inviare contenuti di AutoSupport, oppure se vuoi disabilitare AutoSupport, usa l'opzione *General* > *AutoSupport* dall'interfaccia web.

. Sui sistemi Red Hat, modifica la password dell'utente umadmin dalla stringa predefinita "`admin`" a una stringa personalizzata.
. Nella pagina Configura API Gateway, seleziona se vuoi utilizzare la funzionalità API Gateway che consente a Unified Manager di gestire i cluster ONTAP che intendi monitorare tramite le API REST di ONTAP. Quindi fai clic su *Continua*.
+
In seguito puoi abilitare o disabilitare questa impostazione nell'interfaccia utente web da *Generale* > *Impostazioni funzionalità* > *API Gateway*. Per ulteriori informazioni sulle API, consulta link:../api-automation/concept_get_started_with_um_apis.html["Guida introduttiva alle API REST di Active IQ Unified Manager"].

. Aggiungi i cluster che vuoi far gestire a Unified Manager, quindi fai clic su *Avanti*. Per ogni cluster che prevedi di gestire, devi disporre dell'host name o dell'indirizzo IP di gestione del cluster (IPv4 o IPv6), oltre alle credenziali di nome utente e password; l'utente deve avere il ruolo "`admin`".
+
Questo passaggio è facoltativo. Puoi aggiungere i cluster in un secondo momento nell'interfaccia web da *Storage Management* > *Cluster Setup*.

. Nella pagina Riepilogo, verifica che tutte le impostazioni siano corrette e fai clic su *Finish*.


La pagina "Per iniziare" si chiude e viene visualizzata la pagina "Dashboard di Unified Manager".
