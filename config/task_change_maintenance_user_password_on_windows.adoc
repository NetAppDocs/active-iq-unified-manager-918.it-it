= Cambia la password dell'utente di manutenzione su Windows in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi modificare la password dell'utente di manutenzione di Unified Manager quando necessario.

.Passaggi
. Dalla pagina di accesso dell'interfaccia utente web di Unified Manager, fai clic su *Forgot Password*.
+
Viene visualizzata una pagina che ti chiede di inserire il nome dell'utente di cui vuoi reimpostare la password.

. Inserisci il nome utente e fai clic su *Invia*.
+
Un'email con un link per reimpostare la password viene inviata all'indirizzo email definito per quel nome utente.

. Fai clic sul link *per reimpostare la password* nell'email e definisci la nuova password.
. Torna all'interfaccia web e accedi a Unified Manager usando la nuova password.
