= Abilita la gestione dello storage basata su policy in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'opzione *Gestione dello storage basata su criteri* consente la gestione dello storage in base agli obiettivi di livello di servizio (SLO). Questa opzione è abilitata per impostazione predefinita.

Attivando questa funzionalità, puoi eseguire il provisioning dei carichi di lavoro di storage sui cluster ONTAP aggiunti alla tua istanza di Active IQ Unified Manager e gestire questi carichi di lavoro in base ai Performance Service Levels e alle Storage Efficiency Policies assegnati.

Puoi scegliere di attivare o disattivare questa funzione da *General* > *Feature Settings* > *Policy-based storage management*. Quando attivi questa funzione, le seguenti pagine sono disponibili per il funzionamento e il monitoraggio:

* Provisioning (provisioning dei carichi di lavoro di storage)
* *Politiche* > *Livelli di servizio delle prestazioni*
* *Politiche* > *Efficienza dello storage*
* Colonna Carichi di lavoro gestiti da Performance Service Level nella pagina Configurazione cluster
* Pannello Prestazioni del carico di lavoro nella *Dashboard*


Puoi utilizzare le schermate per creare livelli di servizio delle prestazioni e policy di efficienza dello storage, nonché per eseguire il provisioning dei carichi di lavoro di storage. Puoi anche monitorare i carichi di lavoro di storage conformi ai livelli di servizio delle prestazioni assegnati, oltre a quelli non conformi. Il pannello Prestazioni del carico di lavoro e IOPS del carico di lavoro ti consente anche di valutare la capacità e le prestazioni (IOPS) totali, disponibili e utilizzate dei cluster nel data center in base ai carichi di lavoro di storage di cui è stato eseguito il provisioning.

Dopo aver attivato questa funzionalità, puoi eseguire le API REST di Unified Manager per svolgere alcune di queste funzioni da *Menu Bar* > *Help button* > *API Documentation* > categoria *storage-provider*. In alternativa, puoi immettere l'host name o l'indirizzo IP e l'URL per accedere alla pagina dell'API REST nel formato +https://<hostname>/docs/api/+

Per ulteriori informazioni sulle API, vedi link:../api-automation/concept_get_started_with_um_apis.html["Guida introduttiva alle API REST di Active IQ Unified Manager"].
