= Cambia la password umadmin di Active IQ Unified Manager sui sistemi Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per motivi di sicurezza, devi modificare la password predefinita dell'utente umadmin di Unified Manager immediatamente dopo aver completato il processo di installazione. Se necessario, puoi modificare nuovamente la password in qualsiasi momento.

.Prima di iniziare
* Unified Manager deve essere installato su un sistema Red Hat Enterprise Linux Linux.
* Devi disporre delle credenziali dell'utente root per il sistema Linux su cui è installato Unified Manager.


.Passaggi
. Accedi come utente root al sistema Linux su cui è in esecuzione Unified Manager.
. Modifica la password di umadmin:
+
`passwd umadmin`

+
Il sistema ti chiede di inserire una nuova password per l'utente umadmin.
