= Scopri i menu della console di manutenzione in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La console di manutenzione è composta da diversi menu che ti consentono di eseguire la manutenzione e gestire le funzionalità speciali e le impostazioni di configurazione del server Unified Manager.

A seconda del sistema operativo su cui hai installato Unified Manager, la console di manutenzione è composta dai seguenti menu:

* Aggiorna Unified Manager (solo per VMware)
* Configurazione di rete (solo VMware)
* Configurazione del sistema (solo VMware)
+
.. Supporto/Diagnostica
.. Reimposta il certificato del server
.. Rigenera il certificato client
.. Backup e ripristino
.. Fornitore di dati esterno
.. Configurazione dell'intervallo di polling delle prestazioni
.. Disabilita l'autenticazione SAML
.. Visualizza/Modifica le porte dell'applicazione
.. Configurazione del log di debug
.. Controlla l'accesso alla porta MySQL 3306
.. Esci




Selezioni il numero dall'elenco per accedere alla specifica opzione di menu. Ad esempio, per backup e ripristino, selezioni _4_.
