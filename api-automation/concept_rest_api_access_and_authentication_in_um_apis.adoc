= Accedi e autenticati alle API REST in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'API REST di Active IQ Unified Manager è accessibile tramite qualsiasi client REST o piattaforma di programmazione in grado di inviare richieste HTTP con un meccanismo di autenticazione HTTP di base.

* *Richiesta*
+
[listing]
----
GET
https://<IP address/hostname>:<port_number>/api/v2/datacenter/cluster/clusters
----

+
** `_IP address/hostname_` è l'indirizzo IP o il fully qualified domain name (FQDN) del server API.
** Porta 443
+
La porta HTTPS predefinita è 443. Puoi personalizzare la porta HTTPS, se necessario.



+
Per inviare richieste HTTP da un browser web, devi utilizzare i plugin del browser per REST API. Puoi anche accedere alla REST API utilizzando piattaforme di scripting come cURL e Perl.





[[authentication]]
== Autenticazione

Unified Manager supporta lo schema di autenticazione HTTP di base per le API. Per garantire un flusso di informazioni sicuro (richiesta e risposta), le API REST sono accessibili solo tramite HTTPS. Il server API fornisce a tutti i client un certificato SSL autofirmato per la verifica del server. Questo certificato può essere sostituito da un certificato personalizzato (o da un certificato CA).

Devi configurare l'accesso degli utenti al server API per richiamare le API REST. Gli utenti possono essere utenti locali (profili utente memorizzati nel database locale) o utenti LDAP (se hai configurato il server API per l'autenticazione tramite LDAP). Puoi gestire l'accesso degli utenti accedendo all'interfaccia utente della console di amministrazione di Unified Manager.
