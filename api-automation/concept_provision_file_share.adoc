= Effettua il provisioning delle condivisioni file CIFS e NFS utilizzando le API di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi eseguire il provisioning di CIFS share e condivisioni file NFS sulle tue Storage Virtual Machines (SVM) utilizzando le API di provisioning fornite come parte di Active IQ Unified Manager. Questo flusso di lavoro di provisioning descrive in dettaglio i passaggi per recuperare le chiavi delle SVM, i livelli di servizio delle prestazioni e le policy di efficienza dello storage prima di creare le condivisioni file.

Il diagramma seguente illustra ogni fase del flusso di lavoro per il provisioning di una condivisione file. Include il provisioning sia delle CIFS share sia delle condivisioni file NFS.

image::../media/create_fileshares.gif[Un diagramma che mostra il workflow di provisioning delle condivisioni file CIFS e NFS, dalla configurazione di SVM fino alla creazione della condivisione]

[NOTE]
====
Assicurarsi quanto segue:

* I cluster ONTAP sono stati aggiunti a Unified Manager ed è stata ottenuta la chiave del cluster.
* Le SVM sono state create sui cluster.
* Gli SVM supportano i servizi CIFS e NFS. Il provisioning delle condivisioni di file potrebbe non riuscire se gli SVM non supportano i servizi richiesti.
* La porta FCP è online per il provisioning della porta.


====
. Verifica se sono disponibili Data LIF o endpoint di accesso sull'SVM su cui vuoi creare la CIFS share. Ottieni l'elenco degli endpoint di accesso disponibili sull'SVM:
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Percorso 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/access-endpoints`
`/storage-provider/access-endpoints/\{key}`

|===
+
*Esempio di cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/storage-provider/access-endpoints?resource.key=7d5a59b3-953a-11e8-8857-00a098dcc959" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. Se il tuo endpoint di accesso è presente nell'elenco, ottieni la chiave dell'endpoint di accesso, altrimenti crea l'endpoint di accesso.
+
[NOTE]
====
Assicurati di creare endpoint di accesso con il protocollo CIFS abilitato. Il provisioning delle CIFS share non andrà a buon fine se non hai creato un endpoint di accesso con il protocollo CIFS abilitato.

. Determina se devi creare una CIFS share o una condivisione file NFS. Per creare CIFS share, segui questi passaggi:
+
.. Verifica se il server CIFS è configurato sul tuo SVM, ovvero se sull'SVM è stata creata una mappatura Active Directory.

|===

|===
.. Se la mappatura di Active Directory è stata creata, prendi la chiave, altrimenti crea la mappatura di Active Directory sull'SVM.
+
[cols="3*"]

 a| 
storage-provider
 a|

 a| 
`/storage-provider/active-directories-mappings`

. Facoltativamente, ottieni la chiave di Storage Efficiency Policy per la Storage Efficiency Policy che vuoi applicare alla condivisione file eseguendo la seguente API e recuperando la chiave dalla risposta.

. Crea la condivisione file. Puoi creare una condivisione file che supporti sia CIFS che NFS specificando l'elenco di controllo degli accessi e la policy di esportazione. I sottopassaggi seguenti forniscono informazioni se vuoi creare una condivisione file per supportare solo uno dei protocolli sul volume. Puoi anche aggiornare una condivisione file NFS per includere l'elenco di controllo degli accessi dopo aver creato la condivisione NFS. Per informazioni, consulta l'argomento _Modifying storage workloads_.
+
.. Per creare solo una CIFS share, raccogli le informazioni relative all'elenco di controllo degli accessi (ACL). Per creare la CIFS share, fornisci valori validi per i seguenti parametri di input. Per ogni gruppo di utenti che assegni, viene creato un ACL quando esegui il provisioning di una CIFS/SMB share. In base ai valori che inserisci per ACL e mappatura di Active Directory, il sistema determina il controllo degli accessi e la mappatura per la CIFS share al momento della creazione.
+
*Un comando cURL con valori di esempio*

+
[listing]
----
{
  "access_control": {
    "acl": [
      {
        "permission": "read",
        "user_or_group": "everyone"
      }
    ],
    "active_directory_mapping": {
      "key": "3b648c1b-d965-03b7-20da-61b791a6263c"
    },
----
.. Per creare solo un file share NFS, raccogli le informazioni sulla policy di esportazione. Per creare il file share NFS, fornisci valori validi per i seguenti parametri di input. In base ai valori inseriti, la policy di esportazione viene associata al file share NFS al momento della creazione.
+
[NOTE]
====
Durante il provisioning della condivisione NFS, puoi creare una policy di esportazione fornendo tutti i valori richiesti oppure fornire la chiave della policy di esportazione e riutilizzare una policy di esportazione esistente. Se vuoi riutilizzare una policy di esportazione per la VM di storage, devi aggiungere la chiave della policy di esportazione. A meno che tu non conosca la chiave, puoi recuperare la chiave della policy di esportazione usando l' `/datacenter/protocols/nfs/export-policies`API. Per creare una nuova policy, devi inserire le regole come mostrato nell'esempio seguente. Per le regole inserite, l'API tenta di cercare una policy di esportazione esistente facendo corrispondere host, VM di storage e regole. Se esiste una policy di esportazione, viene utilizzata. In caso contrario, viene creata una nuova policy di esportazione.

====
+
*Un comando cURL con valori di esempio*

[listing]
----
"export_policy": {
      "key": "7d5a59b3-953a-11e8-8857-00a098dcc959:type=export_policy,uuid=1460288880641",
      "name_tag": "ExportPolicyNameTag",
      "rules": [
        {
          "clients": [
            {
              "match": "0.0.0.0/0"
            }
----
