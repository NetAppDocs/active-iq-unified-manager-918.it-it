= Comprendi i flussi di lavoro API comuni per la gestione dello storage in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
I flussi di lavoro comuni forniscono agli sviluppatori di applicazioni client esempi di come le API di Active IQ Unified Manager possono essere richiamate da un'applicazione client per eseguire funzioni comuni di gestione dello storage. Questa sezione contiene alcuni di questi flussi di lavoro di esempio.

I flussi di lavoro descrivono alcuni dei casi d'uso più comuni per la gestione dello storage, insieme a esempi di codice da usare. Ciascuna attività è descritta tramite un processo di flusso di lavoro composto da una o più chiamate API.



[[understand-the-api-calls-used-in-the-workflows]]
== Comprendere le chiamate API utilizzate nei flussi di lavoro

Puoi visualizzare la pagina della documentazione online dalla tua istanza di Unified Manager, che include i dettagli di ogni chiamata REST API. Questo documento non ripete i dettagli della documentazione online. Ogni chiamata API utilizzata negli esempi di flusso di lavoro in questo documento include solo le informazioni necessarie per individuare la chiamata nella pagina della documentazione. Dopo aver individuato una specifica chiamata API, puoi esaminarne i dettagli completi, inclusi i parametri di input, i formati di output, i codici di stato HTTP e il tipo di elaborazione della richiesta.

Le seguenti informazioni sono incluse per ogni chiamata API all'interno di un flusso di lavoro per facilitare l'individuazione della chiamata nella pagina della documentazione:

* Categoria: Le chiamate API sono organizzate nella pagina della documentazione in aree o categorie funzionalmente correlate. Per individuare una chiamata API specifica, scorri fino in fondo alla pagina e fai clic sulla categoria API corrispondente.
* Verbo HTTP (chiamata): Il verbo HTTP identifica l'azione eseguita su una risorsa. Ogni chiamata API viene eseguita tramite un singolo verbo HTTP.
* Percorso: Il percorso determina la risorsa specifica a cui si applica l'azione durante l'esecuzione di una chiamata. La stringa del percorso viene aggiunta all'URL principale per formare l'URL completo che identifica la risorsa.
