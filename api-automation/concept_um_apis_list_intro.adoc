= Scopri le categorie delle API REST di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
In questa sezione sono elencate le API REST per Active IQ Unified Manager, suddivise per categoria.

Puoi visualizzare la pagina della documentazione online dalla tua istanza di Unified Manager, che include i dettagli di ogni chiamata REST API. Questo documento non ripete i dettagli della documentazione online. Ogni chiamata API elencata o descritta in questo documento include solo le informazioni necessarie per individuare la chiamata nella pagina della documentazione. Dopo aver individuato una specifica chiamata API, puoi esaminarne i dettagli completi, inclusi i parametri di input, i formati di output, i codici di stato HTTP e il tipo di elaborazione della richiesta.

Le seguenti informazioni sono incluse per ogni chiamata API all'interno di un flusso di lavoro per facilitare l'individuazione della chiamata nella pagina della documentazione:

* Categoria
+
Le chiamate API sono organizzate nella pagina della documentazione in aree o categorie correlate dal punto di vista funzionale. Per individuare una chiamata API specifica, scorri fino in fondo alla pagina e fai clic sulla categoria API corrispondente.

* Verbo HTTP (chiamata)
+
Il verbo HTTP identifica l'azione eseguita su una risorsa. Ogni chiamata API si esegue tramite un singolo verbo HTTP.

* Percorso
+
Il percorso determina la risorsa specifica che l'azione utilizza nell'esecuzione di una chiamata. La stringa del percorso viene aggiunta all'URL principale per formare l'URL completo che identifica la risorsa.
