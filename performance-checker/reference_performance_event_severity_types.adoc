= Dai priorità agli eventi di performance in base alla gravità in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A ciascun evento relativo alle prestazioni è associato un tipo di severità che consente di dare priorità agli eventi che richiedono un intervento correttivo immediato.

* *Critico*
+
Si è verificato un evento relativo alle prestazioni che potrebbe causare un'interruzione del servizio se non si interviene immediatamente.

+
Gli eventi critici vengono inviati solo al superamento di soglie definite dall'utente.

* *Avvertimento*
+
Un contatore delle prestazioni per un oggetto del cluster è al di fuori dell'intervallo normale e deve essere monitorato per assicurarti che non raggiunga il tipo di severità critico. Gli eventi di questo tipo di severità non causano interruzioni del servizio e potrebbero non richiedere un'azione correttiva immediata.

+
Le soglie definite dall'utente, dal sistema o dinamiche inviano eventi di avviso.

* *Informazioni*
+
L'evento si verifica quando viene rilevato un nuovo oggetto o quando viene eseguita un'azione da parte dell'utente. Ad esempio, quando viene eliminato un qualsiasi oggetto di storage o quando vengono apportate modifiche alla configurazione, viene generato l'evento con tipo di severità Information.

+
ONTAP invia direttamente gli eventi informativi quando rileva una modifica della configurazione.
