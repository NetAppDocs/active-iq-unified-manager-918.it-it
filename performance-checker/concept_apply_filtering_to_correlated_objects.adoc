= Filtra gli oggetti correlati nella griglia di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La funzione di filtro ti consente di visualizzare un sottoinsieme di oggetti più piccolo e ben definito nella griglia. Ad esempio, se nella griglia sono presenti 25 volumi, il filtro ti permette di visualizzare solo quelli con throughput inferiore a 90 MBps o latenza superiore a 1 ms/op.
