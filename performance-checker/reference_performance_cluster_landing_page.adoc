= Esamina la pagina iniziale del cluster Performance in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La pagina Performance Cluster Landing visualizza lo stato high-level delle prestazioni di un cluster selezionato. La pagina ti consente di accedere ai dettagli completi di ciascun contatore delle prestazioni per gli oggetti di archiviazione nel cluster selezionato.

La pagina di destinazione del cluster delle prestazioni include quattro schede che suddividono i dettagli del cluster in quattro aree di informazioni:

* Pagina di riepilogo
+
** Riquadro degli eventi del cluster
** Grafici delle prestazioni in MB/s e IOPS
** Riquadro degli oggetti gestiti


* Pagina dei Top Performers
* Pagina Explorer
* Pagina informativa
