= Invia i dati sulle prestazioni di Active IQ Unified Manager a un server esterno
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager raccoglie una varietà di dati sulle prestazioni da tutti i cluster che monitora. Puoi inviare gruppi specifici di dati a un server esterno.

A seconda dei dati sulle prestazioni che vuoi rappresentare graficamente, puoi scegliere di inviare uno dei seguenti gruppi di statistiche:

|===
| Gruppo di statistiche | Dati inclusi | Dettagli 


 a| 
Monitoraggio delle prestazioni
 a| 
Statistiche high-level per i seguenti oggetti:

* LUN
* Volumi

 a| 
Questo gruppo fornisce gli IOPS o la latenza totali per tutte le LUN e i volumi in tutti i cluster monitorati.

Questo gruppo fornisce il minor numero di statistiche.



 a| 
Utilizzo delle risorse
 a| 
Statistiche di utilizzo delle risorse per i seguenti oggetti:

* Nodi
* Aggregati

 a| 
Questo gruppo fornisce statistiche di utilizzo per le risorse fisiche del nodo e dell'aggregato in tutti i cluster monitorati.

Fornisce inoltre le statistiche raccolte nel gruppo Performance Monitor.



 a| 
Approfondimento
 a| 
Statistiche di lettura/scrittura low-level e statistiche per protocollo per tutti gli oggetti monitorati:

* Nodi
* Aggregati
* LUN
* Volumi
* Dischi
* LIF
* Porte/Schede di rete

 a| 
Questo gruppo fornisce dettagli sulle operazioni di lettura/scrittura e per protocollo per tutti e sette i tipi di oggetti tracciati in tutti i cluster monitorati.

Fornisce inoltre le statistiche raccolte nel gruppo Monitoraggio delle prestazioni e nel gruppo Utilizzo delle risorse.

Questo gruppo fornisce il maggior numero di statistiche.

|===
[NOTE]
====
Se modifichi il nome di un cluster o di un oggetto del cluster sul sistema storage, sia il vecchio sia il nuovo oggetto conterranno dati sulle prestazioni sul server esterno (denominato "`metric_path`"). I due oggetti non sono correlati come se fossero lo stesso oggetto. Ad esempio, se modifichi il nome di un volume da "`volume1_acct`" a "`acct_vol1`", vedrai i vecchi dati sulle prestazioni per il vecchio volume e i nuovi dati sulle prestazioni per il nuovo volume.

====
