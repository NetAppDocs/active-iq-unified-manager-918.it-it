= Analizza gli eventi derivanti dalle soglie di prestazione definite dal sistema in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gli eventi generati dalle soglie di prestazioni definite dal sistema indicano che un contatore di prestazioni, o un insieme di contatori di prestazioni, per un determinato oggetto di archiviazione ha superato la soglia definita da una policy di sistema. Ciò indica che l'oggetto di archiviazione, ad esempio un aggregato o un nodo, sta riscontrando un problema di prestazioni.

Usi la pagina Dettagli evento per analizzare l'evento relativo alle prestazioni e, se necessario, intraprendere azioni correttive per riportare le prestazioni alla normalità.

[NOTE]
====
Le policy di soglia definite dal sistema non sono abilitate sui sistemi Cloud Volumes ONTAP, ONTAP Edge o ONTAP Select.

====
