= Pianifica le operazioni di efficienza dello storage nei momenti meno impegnativi in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi modificare la policy o la pianificazione che gestisce le operazioni di efficienza dello storage in modo che vengano eseguite quando i workload dei volumi interessati sono meno intensi.

Le operazioni di ottimizzazione dello storage possono utilizzare una grande quantità di risorse della CPU del cluster e penalizzare i volumi su cui vengono eseguite. Se i volumi interessati presentano un'attività elevata contemporaneamente all'esecuzione delle operazioni di ottimizzazione dello storage, la loro latenza può aumentare e innescare un evento.

Nella pagina Dettagli evento, la sezione Diagnosi di sistema visualizza i carichi di lavoro nel gruppo di policy QoS in base alla deviazione di picco dell'attività per identificare i carichi di lavoro problematici. Se nella parte superiore della tabella viene visualizzata la dicitura "`storage efficiency`", queste operazioni stanno penalizzando i carichi di lavoro interessati. Se modifichi la policy di efficienza o la pianificazione in modo che vengano eseguite quando questi carichi di lavoro sono meno occupati, puoi evitare che le operazioni di storage efficiency causino contesa su un cluster.

Puoi usare ONTAP System Manager per gestire le policy di efficienza. Puoi usare i comandi ONTAP per gestire le policy e le pianificazioni di efficienza.
