= Espandi il riquadro Grafici contatore in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi espandere il riquadro Grafici contatore in modo che i grafici siano più grandi e più leggibili.

Dopo aver definito gli oggetti di confronto e l'intervallo di tempo per i contatori, puoi visualizzare un riquadro Counter Charts più ampio. Per espandere il riquadro, usa il pulsante *<* al centro della finestra Performance Explorer.

.Passaggio
. Espandi o riduci il riquadro *Grafici dei contatori*.


|===
| A... | Fai così... 


 a| 
Espandi il riquadro Counter Charts in modo che si adatti alla larghezza della pagina
 a| 
Fai clic sul pulsante *<*



 a| 
Riduci il riquadro dei grafici dei contatori alla metà destra della pagina
 a| 
Fai clic sul pulsante *>*

|===
