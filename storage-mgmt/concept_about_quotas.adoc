= Scopri le quote in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le quote consentono di limitare o monitorare lo spazio su disco e il numero di file utilizzati da un utente, un gruppo o un qtree. Specifichi le quote utilizzando il file  `/etc/quotas`. Le quote vengono applicate a un volume o a un qtree.
