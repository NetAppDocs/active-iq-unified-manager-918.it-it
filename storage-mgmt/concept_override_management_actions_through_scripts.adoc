= Sovrascrivi le azioni di gestione con script in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi creare script personalizzati e associarli agli avvisi per eseguire azioni specifiche per eventi specifici, invece di scegliere le azioni di gestione predefinite disponibili nella pagina Management Actions o nella dashboard di Unified Manager.

Se vuoi intraprendere azioni specifiche per un tipo di evento e scegli di non correggerle nell'ambito della funzionalità Management Actions fornita da Unified Manager, puoi configurare uno script personalizzato per l'azione specifica. Puoi quindi associare lo script a un avviso per quel tipo di evento e gestire tali eventi singolarmente. In questo caso, non vengono generate Management Actions per quel tipo di evento specifico nella pagina Management Actions o nella dashboard di Unified Manager.
