= Visualizza e aggiungi vCenter Server in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Per visualizzare e risolvere i problemi relativi alle prestazioni delle macchine virtuali (VM), devi aggiungere i vCenter Server associati alla tua istanza di Active IQ Unified Manager.

.Prima di iniziare
Prima di aggiungere o visualizzare i server vCenter, assicurati di quanto segue:

* Conosci i nomi dei server vCenter.
* Conosci l'indirizzo IP di vCenter Server e disponi delle credenziali necessarie. Le credenziali devono essere quelle di un amministratore di vCenter Server o di un utente root con accesso in sola lettura a vCenter Server.
* Il server vCenter che vuoi aggiungere esegue vSphere 6.5 o versione successiva.
+

NOTE: Il supporto di Unified Manager per VMware ESXi e vCenter Server è disponibile in inglese e giapponese.

* L'impostazione di raccolta di dati in vCenter Server è impostata sul livello di statistiche di  `_Level 3_`, garantendo il livello richiesto di raccolta delle metriche per tutti gli oggetti monitorati. La durata dell'intervallo dovrebbe essere  `_5 minutes_` e il periodo di salvataggio dovrebbe essere  `_1 day_`.
+
Per ulteriori informazioni, consulta la sezione "`Data Collection Levels`" di _vSphere Monitoring and Performance Guide_ nella documentazione VMware.

* I valori di latenza in vCenter Server sono configurati in millisecondi e non in microsecondi, per calcolare correttamente i valori di latenza.
* Quando aggiungi il datastore a vCenter Server, puoi utilizzare sia l'indirizzo IP dell'host sia il fully qualified domain name (FQDN). Se aggiungi l'FQDN, assicurati che il domain name possa essere risolto dal server Unified Manager. Ad esempio, per un'installazione Linux, assicurati che il domain name sia aggiunto al file  `/etc/resolv.conf`.
* L'ora corrente del server vCenter è sincronizzata con il fuso orario del server vCenter.
* vCenter Server è raggiungibile per un rilevamento riuscito.
* Hai accesso in lettura a VMware SDK quando aggiungi il vCenter Server a Unified Manager. Questo è necessario per il polling della configurazione.


Per ogni server vCenter aggiunto e rilevato, Unified Manager raccoglie i dati di configurazione, come i dettagli del server vCenter e del server ESXi, la mappatura ONTAP, i dettagli del datastore e il numero di macchine virtuali ospitate. Inoltre, raccoglie le metriche delle prestazioni dei componenti.

.Passaggi
. Vai su *VMWARE* > *vCenter*, e verifica se il tuo server vCenter è presente nell'elenco.
+
[NOTE]
====
Se il tuo server vCenter non è disponibile, devi aggiungere vCenter Server.

====
+
.. Fai clic su *Add*.
.. Aggiungi l'indirizzo IP corretto per vCenter Server e assicurati che il dispositivo sia raggiungibile.
.. Aggiungi il nome utente e la password dell'amministratore o dell'utente root con accesso in sola lettura a vCenter Server.
.. Aggiungi il numero di porta personalizzato se utilizzi una porta diversa da quella predefinita 443.
.. Fare clic su *Save*.
+
Al termine del rilevamento, viene visualizzato un certificato del server che puoi accettare.

+
Quando accetti il certificato, vCenter Server viene aggiunto all'elenco dei vCenter Server disponibili. L'aggiunta del dispositivo non comporta la raccolta di dati per le VM associate e la raccolta avviene a intervalli programmati.



. Se il tuo vCenter Server è disponibile nella pagina *vCenters*, controllane lo stato passando il mouse sul campo *Status* per visualizzare se il tuo vCenter Server funziona come previsto o se è presente un avviso o un errore.
+
[NOTE]
====
L'aggiunta di vCenter Server ti consente di visualizzare i seguenti stati. Tuttavia, i dati relativi alle prestazioni e alla latenza delle VM corrispondenti potrebbero impiegare fino a un'ora dopo l'aggiunta di vCenter Server per essere visualizzati correttamente.

====
+
** Verde: "Normale", a indicare che il server vCenter è stato rilevato e che le metriche delle prestazioni sono state raccolte correttamente
** Giallo: "Avviso" (ad esempio, quando il livello delle statistiche per il server vCenter non è stato impostato su 3 o superiore per ottenere statistiche per ciascun oggetto)
** Arancione: "Errore" (indica eventuali errori interni, come eccezioni, errori nella raccolta dei dati di configurazione o vCenter Server non raggiungibile) Puoi fare clic sull'icona di visualizzazione della colonna (*Mostra/Nascondi*) per visualizzare il messaggio di stato di un vCenter Server e risolvere il problema.


. Se vCenter Server non è raggiungibile o le credenziali sono cambiate, modifica i dettagli di vCenter Server selezionando *vCenter* > *Modifica*.
. Apporta le modifiche necessarie nella pagina *Modifica server VMware vCenter*.
. Fare clic su *Save*.


*vCenter Inizio della raccolta di dati del server*

vCenter Server raccoglie campioni di dati sulle prestazioni real-time ogni 20 secondi e li aggrega in campioni di 5 minuti. La pianificazione della raccolta di dati sulle prestazioni di Unified Manager si basa sulle impostazioni predefinite di vCenter Server. Unified Manager elabora i campioni di 5 minuti ottenuti da vCenter Server e calcola una media oraria di IOPS e latenza per i dischi virtuali, le VM e gli host. Per i datastore, Unified Manager calcola una media oraria di IOPS e latenza dai campioni ottenuti da ONTAP. Questi valori sono disponibili all'inizio di ogni ora. Le metriche delle prestazioni non sono disponibili subito dopo l'aggiunta di vCenter Server, ma diventano disponibili solo all'inizio dell'ora successiva. Il polling dei dati sulle prestazioni inizia al completamento di un ciclo di raccolta dei dati di configurazione.

Per il polling dei dati di configurazione di vCenter Server, Unified Manager segue la stessa pianificazione della raccolta di dati di configurazione del cluster. Per informazioni sulla pianificazione della raccolta di dati di configurazione e delle prestazioni di vCenter Server, consulta "Attività di raccolta di dati di configurazione e delle prestazioni del cluster".
