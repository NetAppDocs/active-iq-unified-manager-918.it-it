= Scopri la replica dei dati FC di MetroCluster in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le configurazioni MetroCluster over FC offrono il mirroring dei dati e l'ulteriore possibilità di avviare un failover se un intero sito diventa non disponibile. Lo stato del mirroring dei dati tra i cluster in una configurazione MetroCluster over FC può essere Normal o Mirroring Unavailable. Comprendere lo stato ti consente di gestire le configurazioni MetroCluster in modo efficace.

|===
| Stato di mirroring dei dati | Descrizione | Icona visualizzata 


 a| 
Normale
 a| 
La replica dei dati tra i cluster nella configurazione MetroCluster è normale.
 a| 
image:../media/metrocluster_connectivity_optimal.gif["icona di connettività ottimale di MetroCluster"]



 a| 
Mirroring non disponibile
 a| 
Il mirroring dei dati tra i cluster nella configurazione MetroCluster non è disponibile a causa dello switchover. Ad esempio, quando il cluster partner non è disponibile a causa di un disastro o quando è previsto uno switchover per scopi di test.
 a| 
Passaggio di consegne con errori:

image::../media/metrocluster_connectivity_down.gif[icona di connettività MetroCluster non attiva]

Commutazione riuscita:

image::../media/metrocluster_connectivity_failover.gif[icona di failover della connettività di metrocluster]

|===
