= Monitora e gestisci i cluster dalla dashboard di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La dashboard fornisce informazioni cumulative e immediate sullo stato di salute attuale dei tuoi sistemi ONTAP monitorati. La dashboard offre dei "`pannelli`" che ti consentono di valutare la capacità complessiva, le prestazioni e lo stato di sicurezza dei cluster che monitori.

Inoltre, ci sono alcuni problemi di ONTAP che puoi risolvere direttamente dall'interfaccia utente di Unified Manager invece di dover usare ONTAP System Manager o ONTAP CLI.

Nella parte superiore della dashboard puoi selezionare se i pannelli mostrano informazioni per tutti i cluster monitorati o per un singolo cluster. Puoi iniziare visualizzando lo stato di tutti i cluster e poi passare ai singoli cluster quando vuoi visualizzare informazioni dettagliate.

[NOTE]
====
Alcuni dei pannelli elencati di seguito potrebbero non essere visualizzati nella pagina a seconda della configurazione.

====
|===
| Pannelli | Descrizione 


 a| 
Azioni di gestione
 a| 
Quando Unified Manager è in grado di diagnosticare e determinare un'unica soluzione per un problema, questa viene visualizzata in questo pannello con un pulsante *Fix It*.



 a| 
Capacità
 a| 
Visualizza la capacità totale e quella utilizzata per il livello locale e per il livello cloud, nonché il numero di giorni prima che la capacità locale raggiunga il limite massimo.



 a| 
Capacità di performance
 a| 
Visualizza il valore della capacità prestazionale per ciascun cluster e il numero di giorni rimanenti prima che la capacità prestazionale raggiunga il limite massimo.



 a| 
IOPS del carico di lavoro
 a| 
Visualizza il numero totale di carichi di lavoro attualmente in esecuzione in un determinato intervallo di IOPS.



 a| 
Prestazioni del carico di lavoro
 a| 
Visualizza il numero totale di carichi di lavoro conformi e non conformi assegnati a ciascun livello di servizio delle prestazioni definito.



 a| 
Sicurezza
 a| 
Visualizza il numero di cluster conformi o non conformi, il numero di SVM conformi o non conformi e il numero di volumi crittografati o non crittografati.



 a| 
Protezione
 a| 
Visualizza il numero di Storage VM protette dalla relazione SVM-DR, i volumi protetti dalla relazione di SnapMirror, i volumi protetti da Snapshot e i cluster protetti da MetroCluster.



 a| 
Panoramica sull'utilizzo
 a| 
Visualizza i cluster ordinati in base agli IOPS più elevati, al throughput più elevato (MBps) o alla capacità fisica utilizzata più elevata.

|===
