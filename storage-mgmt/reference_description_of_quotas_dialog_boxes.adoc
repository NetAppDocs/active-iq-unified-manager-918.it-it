= Usa la finestra di dialogo Quote in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nella vista Health: All Storage VMs, puoi usare l'opzione appropriata nella scheda User and Group Quotas per configurare il formato della notifica e-mail inviata quando si verifica un problema relativo alle quote e per configurare le regole che specificano gli indirizzi e-mail in base alla quota utente.
