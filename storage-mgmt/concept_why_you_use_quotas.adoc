= Scopri le quote in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi utilizzare le quote per limitare l'utilizzo delle risorse nei volumi FlexVol, per ricevere notifiche quando l'utilizzo delle risorse raggiunge livelli specifici o per monitorare l'utilizzo delle risorse.

Specifichi una quota per i seguenti motivi:

* Per limitare la quantità di spazio su disco o il numero di file che possono essere utilizzati da un utente o da un gruppo, o che possono essere contenuti in un qtree
* Per tenere traccia della quantità di spazio su disco o del numero di file utilizzati da un utente, un gruppo o un qtree, senza imporre un limite
* Per avvisare gli utenti quando l'utilizzo del disco o dei file è elevato
