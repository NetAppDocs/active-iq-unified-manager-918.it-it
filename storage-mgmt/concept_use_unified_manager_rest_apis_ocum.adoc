= Usa le API REST di Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager ti fornisce API REST per visualizzare le informazioni sul monitoraggio e sulla gestione del tuo ambiente di storage. Le API consentono inoltre di eseguire il provisioning e gestire gli oggetti di storage in base alle policy.

Puoi anche eseguire le API ONTAP su tutti i cluster gestiti da ONTAP utilizzando il gateway API supportato da Unified Manager.

Per informazioni sulle API REST di Unified Manager, consulta link:../api-automation/concept_get_started_with_um_apis.html["Guida introduttiva alle API REST di Active IQ Unified Manager"].
