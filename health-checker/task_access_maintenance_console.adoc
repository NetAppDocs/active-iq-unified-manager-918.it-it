= Accedi alla console di manutenzione in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se l'interfaccia utente di Unified Manager non è operativa, o se devi eseguire funzioni non disponibili nell'interfaccia utente, puoi accedere alla console di manutenzione per gestire il tuo sistema Unified Manager.

.Prima di iniziare
Devi aver installato e configurato Unified Manager.

Dopo 15 minuti di inattività, la console di manutenzione ti disconnette.

[NOTE]
====
Se è installato su VMware, se hai già effettuato l'accesso come utente di manutenzione tramite la console VMware, non puoi accedere contemporaneamente usando Secure Shell.

====
.Passaggio
. Segui questi passaggi per accedere alla console di manutenzione:
+
[cols="2*"]
|===
| Su questo sistema operativo... | Segui questi passaggi... 


 a| 
VMware
 a| 
.. Usando Secure Shell, connettiti all'indirizzo IP o al fully qualified domain name dell'appliance virtuale di Unified Manager.
.. Accedi alla console di manutenzione utilizzando il tuo nome utente e la password di manutenzione.




 a| 
Linux
 a| 
.. Usando Secure Shell, connettiti all'indirizzo IP o al fully qualified domain del sistema Unified Manager.
.. Accedi al sistema con il nome utente e la password dell'utente di manutenzione (umadmin).
.. Inserisci il comando `maintenance_console` e premi Invio.




 a| 
Windows
 a| 
.. Accedi al sistema Unified Manager con le credenziali di amministratore.
.. Avvia PowerShell come amministratore di Windows.
.. Inserisci il comando `maintenance_console` e premi Invio.


|===
+
Viene visualizzato il menu della console di manutenzione di Unified Manager.
