= Scopri il ripristino del database in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il ripristino di un database MySQL è il processo di ripristino di un file di backup esistente di Unified Manager nello stesso server Unified Manager o in un server Unified Manager diverso. Esegui l'operazione di ripristino dalla console di manutenzione di Unified Manager.

Se esegui un'operazione di ripristino sullo stesso sistema (locale) e tutti i file di backup sono archiviati localmente, puoi eseguire l'opzione di ripristino utilizzando la posizione predefinita. Se esegui un'operazione di ripristino su un sistema Unified Manager diverso (un sistema remoto), devi copiare il file, o i file, di backup dallo storage secondario al disco locale prima di eseguire l'opzione di ripristino.

Durante il processo di ripristino, verrai disconnesso da Unified Manager. Potrai accedere nuovamente al sistema al termine del processo di ripristino.

Se ripristini l'immagine di backup su un nuovo server, al termine dell'operazione di ripristino devi generare un nuovo certificato di sicurezza HTTPS e riavviare il server Unified Manager. Dovrai inoltre riconfigurare le impostazioni di autenticazione SAML, se richieste, quando ripristini l'immagine di backup su un nuovo server.

[NOTE]
====
I vecchi file di backup non possono essere utilizzati per ripristinare un'immagine dopo aver aggiornato Unified Manager a una versione più recente del software. Per risparmiare spazio, tutti i vecchi file di backup, ad eccezione del più recente, vengono rimossi automaticamente durante l'aggiornamento di Unified Manager.
