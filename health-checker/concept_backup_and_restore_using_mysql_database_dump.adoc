= Backup e ripristino utilizzando un dump del database MySQL in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Un backup del dump del database MySQL è una copia del database e dei file di configurazione di Active IQ Unified Manager che puoi utilizzare in caso di guasto del sistema o perdita di dati. Puoi pianificare la scrittura di un backup in una destinazione locale o in una destinazione remota. Ti consigliamo vivamente di definire una posizione remota esterna al sistema host di Active IQ Unified Manager.

[NOTE]
====
Il backup del database MySQL è il meccanismo di backup predefinito quando Unified Manager è installato su un server Linux o Windows. Tuttavia, se Unified Manager gestisce un numero elevato di cluster e nodi, o se i backup MySQL richiedono molte ore per essere completati, puoi eseguire il backup utilizzando copie Snapshot. Questa funzionalità è disponibile su Red Hat Enterprise Linux e Windows.

====
Un backup dump del database consiste in un singolo file nella directory di backup e in uno o più file nella directory del repository del database. Il file nella directory di backup è molto piccolo perché contiene solo un puntatore ai file che si trovano nella directory del repository del database e che sono necessari per ricreare il backup.

La prima volta che generi un backup del database, viene creato un singolo file nella directory di backup e un file di backup completo nella directory del repository del database. La volta successiva che generi un backup, viene creato un singolo file nella directory di backup e un file di backup incrementale nella directory del repository del database che contiene le differenze rispetto al file di backup completo. Questo processo continua man mano che crei backup aggiuntivi, fino all'impostazione di conservazione massima, come mostrato nella figura seguente.

image::../media/database_backup.gif[Un diagramma che mostra tre file di directory di backup che puntano a file completi e incrementali nel repository del database]

[NOTE]
====
Non rinominare né eliminare alcuno dei file di backup presenti in queste due directory, altrimenti qualsiasi successiva operazione di ripristino non andrà a buon fine.

====
Se scrivi i file di backup nel sistema locale, dovresti avviare una procedura per copiarli in una posizione remota, in modo che siano disponibili in caso di problemi di sistema che richiedono un ripristino completo.

Prima di avviare un'operazione di backup, Active IQ Unified Manager esegue un controllo di integrità per verificare che tutti i file e le directory di backup necessari esistano e siano scrivibili. Verifica inoltre che ci sia spazio sufficiente sul sistema per creare il file di backup.
