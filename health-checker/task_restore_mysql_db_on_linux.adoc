= Ripristina un backup del database MySQL su un sistema Linux in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se si verifica una perdita o una corruzione dei dati, puoi ripristinare Unified Manager allo stato stabile precedente con una perdita minima di dati. Puoi ripristinare il database di Unified Manager su un sistema Red Hat Enterprise Linux locale o remoto utilizzando la console di manutenzione di Unified Manager.

.Prima di iniziare
* Devi disporre delle credenziali dell'utente root per l'host Linux su cui è installato Unified Manager.
* Per accedere alla console di manutenzione del server Unified Manager, devi disporre di un ID utente e di una password autorizzati.
* Devi aver copiato il file di backup di Unified Manager e il contenuto della directory del repository del database nel sistema su cui eseguirai l'operazione di ripristino.
+
Si consiglia di copiare il file di backup nella directory predefinita /`data/ocum`-backup. I file del repository del database devono essere copiati nella sottodirectory /`database-dumps-repo` sotto la directory /`ocum-backup`.

* I file di backup devono essere di `.7z` tipo.


La funzionalità di ripristino è specifica per piattaforma e versione. Puoi ripristinare un backup di Unified Manager solo sulla stessa versione di Unified Manager. Puoi ripristinare un file di backup Linux o un file di backup di un'appliance virtuale su un sistema Red Hat Enterprise Linux.

[TIP]
====
Se il nome della cartella di backup contiene uno spazio, devi includere il percorso assoluto o relativo tra virgolette doppie.

====
.Passaggi
. Se esegui un ripristino su un nuovo server, dopo aver installato Unified Manager non avviare l'interfaccia utente né configurare cluster, utenti o impostazioni di autenticazione al termine dell'installazione. Il file di backup compila automaticamente queste informazioni durante il processo di ripristino.
. Usando Secure Shell, connettiti all'indirizzo IP o al fully qualified domain del sistema Unified Manager.
. Accedi al sistema con il nome utente e la password dell'utente di manutenzione (umadmin).
. Inserisci il comando `maintenance_console` e premi Invio.
. Nella console di manutenzione *Main Menu*, inserisci il numero dell'opzione *Backup Restore*.
. Inserisci il numero di *Restore MySQL Backup*.
. Quando richiesto, immetti il percorso assoluto del file di backup.
+
[listing]
----
Bundle to restore from: /data/ocum-backup/UM_9.8.N151113.1348_backup_rhel_02-20-2020-04-45.7z
----
+
Al termine dell'operazione di ripristino, puoi accedere a Unified Manager.



Dopo aver ripristinato il backup, se il server OnCommand Workflow Automation non funziona, esegui i seguenti passaggi:

. Sul server Workflow Automation, modifica l'indirizzo IP del server Unified Manager in modo che punti alla macchina più recente.
. Sul server Unified Manager, reimposta la password del database se l'acquisizione non riesce al passaggio 1.
