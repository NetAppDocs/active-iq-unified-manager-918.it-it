= Aggiorna Active IQ Unified Manager su Windows
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi aggiornare Unified Manager 9.14 o 9.16 alla 9.18 scaricando ed eseguendo il file di installazione sulla piattaforma Windows.

.Prima di iniziare
* Il sistema su cui stai eseguendo l'aggiornamento di Unified Manager deve soddisfare i requisiti di sistema e software.
+
Vedi link:concept_virtual_infrastructure_or_hardware_system_requirements.html["Requisiti hardware del sistema"].

+
Vedi link:reference_windows_software_and_installation_requirements.html["Requisiti software e di installazione per Windows"].

+
[NOTE]
====
A partire da Unified Manager 9.5, OpenJDK è incluso nel pacchetto di installazione e viene installato automaticamente. Oracle Java non è supportato a partire da Unified Manager 9.5.

====
+
[NOTE]
====
Assicurati che Microsoft .NET 4.5.2 o versione successiva sia installato sul tuo sistema prima di iniziare l'aggiornamento.

====
* MySQL Community Edition viene aggiornato automaticamente durante l'aggiornamento di Unified Manager. Se la versione di MySQL installata sul tuo sistema è precedente alla 8.4.10, il processo di aggiornamento di Unified Manager aggiorna automaticamente MySQL alla 8.4.10. Non devi eseguire un aggiornamento autonomo di una versione precedente di MySQL alla 8.4.10.
* Sono supportati tutti i cluster, ad eccezione dei sistemi ASA r2.
* Dovresti disporre dei privilegi di amministratore di Windows. Assicurati che il tuo nome utente non inizi con un punto esclamativo "`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`".
* Per accedere al NetApp Support Site, devi disporre di credenziali valide.
* Per evitare la perdita di dati, dovresti aver creato un backup della macchina Unified Manager nel caso in cui si verifichino problemi durante l'aggiornamento.
* Dovresti avere spazio su disco sufficiente per eseguire l'aggiornamento.
+
Lo spazio disponibile sull'unità di installazione deve essere di 2,5 GB superiore alla dimensione della directory dei dati. L'aggiornamento si interrompe e visualizza un messaggio di errore che indica la quantità di spazio da aggiungere se non c'è spazio libero sufficiente.

* Durante l'aggiornamento, potresti dover confermare se vuoi mantenere le precedenti impostazioni predefinite per conservare i dati sulle prestazioni per 13 mesi o modificarle a 6 mesi. Quando confermi, il sistema elimina i dati storici sulle prestazioni più vecchi di 6 mesi.
* Prima di eseguire l'aggiornamento, devi chiudere tutti i file o le cartelle aperti in _<InstallDir>\JDK_ e _MySQL Data Directory_.
* Se sul tuo sistema Windows è installato un software antivirus attivo, l'aggiornamento di Unified Manager potrebbe non riuscire. Prima di aggiornare Unified Manager, dovresti disattivare tutti i software antivirus sul tuo sistema.


Durante il processo di aggiornamento, Unified Manager non è disponibile. Dovresti completare tutte le operazioni in corso prima di aggiornare Unified Manager.

Se Unified Manager è associato a un'istanza di OnCommand Workflow Automation e sono disponibili nuove versioni del software per entrambi i prodotti, devi disconnettere i due prodotti e quindi configurare una nuova connessione a Workflow Automation dopo aver eseguito gli aggiornamenti. Se esegui l'upgrade di un solo prodotto, devi accedere a Workflow Automation dopo l'upgrade e verificare che stia ancora acquisendo dati da Unified Manager.

.Passaggi
. Accedi al sito di supporto NetApp e vai alla pagina di download di Unified Manager:
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["Sito di supporto NetApp"^].

. Seleziona la versione richiesta di Unified Manager e accetta il contratto di licenza con l'utente finale (EULA).
. Scarica il file di installazione di Unified Manager per Windows o il file zip in una directory di destinazione sul sistema Windows. Estrai il file zip, se necessario, e accedi alla directory in cui si trova il file di installazione. Fai clic con il pulsante destro del mouse sul file eseguibile (.exe) del programma di installazione di Unified Manager ed eseguilo come amministratore.
+
Unified Manager visualizza il seguente messaggio:

+
[listing]
----
This setup will perform an upgrade of Unified Manager. Do you want to continue?
----
. Fai clic su *Sì*, quindi fai clic su *Avanti*.
. Inserisci la password di root di MySQL84 impostata durante l'installazione, quindi fai clic su *Avanti*.
. Avvia l'interfaccia utente web in una nuova finestra di un browser web supportato e accedi per utilizzare la versione aggiornata di Unified Manager.
. Se sul tuo sistema Windows è installato un software antivirus attivo, assicurati di escludere manualmente i seguenti percorsi dalla scansione antivirus al termine dell'aggiornamento:
+
** directory dei dati di Unified Manager
** directory di installazione di Unified Manager
** Directory dati MySQL




[NOTE]
====
Per eseguire un aggiornamento silenzioso di Unified Manager, esegui il seguente comando:
`ActiveIQUnifiedManager-<version\>.exe /s /v"MYSQL_PASSWORD=<password> /qn /l*v <system_drive>:\install.log"`
