= Installa Active IQ Unified Manager su Windows
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi installare Unified Manager per monitorare e risolvere i problemi relativi a capacità, disponibilità, prestazioni e protezione dello storage dei dati.

.Prima di iniziare
* Il sistema su cui intendi installare Unified Manager deve soddisfare i requisiti di sistema e software.
+
Vedi link:concept_virtual_infrastructure_or_hardware_system_requirements.html["Requisiti hardware del sistema"].

+
Vedi link:reference_windows_software_and_installation_requirements.html["Requisiti software e di installazione per Windows"].

+
[NOTE]
====
A partire da Unified Manager 9.5, OpenJDK è incluso nel pacchetto di installazione e viene installato automaticamente. Oracle Java non è supportato a partire da Unified Manager 9.5.

====
* Dovresti disporre dei privilegi di amministratore di Windows. Assicurati che il tuo nome utente non inizi con un punto esclamativo "`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`".
* Sono supportati tutti i cluster, ad eccezione dei sistemi ASA r2.
* Dovresti disporre di un browser web supportato.
* La password dell'utente di manutenzione di Unified Manager deve essere compresa tra 8 e 20 caratteri e deve contenere lettere maiuscole o minuscole, numeri e caratteri speciali.
* I seguenti caratteri speciali non sono consentiti nella stringa della password per l'utente di manutenzione o per l'utente root MySQL: " ' ` % , = & < > | ^ \ / ( ) [ ] ;:
+
Sono consentiti i seguenti caratteri speciali: ~ ! @ # $ * - ? . + { }



.Passaggi
. Accedi a Windows utilizzando l'account amministratore locale predefinito.
. Accedi al sito di supporto NetApp e vai alla pagina di download di Unified Manager:
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["Sito di supporto NetApp"^]

. Seleziona la versione richiesta di Unified Manager e accetta il contratto di licenza con l'utente finale (EULA).
. Scarica il file di installazione di Unified Manager per Windows o il file zip in una directory di destinazione sul sistema Windows.
. Se necessario, estrai il file zip e accedi alla directory in cui si trova il file di installazione.
. Fai clic con il pulsante destro del mouse ed esegui il file eseguibile (.exe) del programma di installazione di Unified Manager come amministratore.
+
Unified Manager rileva i pacchetti di terze parti mancanti o preinstallati e li elenca. Se i pacchetti di terze parti necessari non sono installati nel sistema, Unified Manager li installa durante l'installazione.

. Fare clic su *Avanti*.
. Inserisci il nome utente e la password per creare l'utente di manutenzione.
. Nella procedura guidata di connessione al database, immetti la password di root di MySQL.
. Fai clic su *Change* per specificare una nuova posizione per la directory di installazione di Unified Manager e la directory dei dati MySQL.
+
Se non cambi la directory di installazione, Unified Manager viene installato nella directory di installazione predefinita.

. Fare clic su *Avanti*.
. Nella procedura guidata "Ready to Install Shield", fai clic su *Install*.
. Al termine dell'installazione, fai clic su *Finish*.
. Se sul tuo sistema Windows è installato un software antivirus attivo, escludi manualmente i seguenti percorsi dalla scansione antivirus al termine dell'installazione:
+
** directory dei dati di Unified Manager
** directory di installazione di Unified Manager
** Directory dati MySQL




L'installazione crea più directory:

* directory di installazione
+
Questa è la directory principale di Unified Manager che hai specificato durante l'installazione. Esempio: `C:\Program Files\NetApp\`

* Directory dati MySQL
+
Questa è la directory in cui sono memorizzati i database MySQL, che hai specificato durante l'installazione. Esempio: `C:\ProgramData\MySQL\MySQLServerData\`

* directory di Java
+
Questa è la directory in cui è installato OpenJDK. Esempio: `C:\Program Files\NetApp\JDK\`

* Directory dei dati dell'applicazione di Unified Manager (appDataDir)
+
Questa è la directory in cui sono archiviati tutti i dati generati dall'applicazione. Include log, pacchetti di supporto, backup e tutti gli altri dati aggiuntivi. Esempio: `C:\ProgramData\NetApp\OnCommandAppData\`



Puoi accedere all'interfaccia utente web per eseguire la configurazione iniziale di Unified Manager, come descritto nel link:../config/concept_configure_unified_manager.html["Configurazione di Active IQ Unified Manager"].
