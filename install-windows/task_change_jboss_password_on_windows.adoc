= Cambia la password di JBoss su Windows in Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi reimpostare la password specifica dell'istanza di JBoss impostata durante l'installazione. Puoi reimpostare la password facoltativamente, se il tuo sito richiede questa funzionalità di sicurezza per sovrascrivere l'impostazione di installazione di Unified Manager. Questa operazione modifica anche la password che JBoss utilizza per accedere a MySQL.

.Prima di iniziare
* Devi disporre dei privilegi di amministratore di Windows per il sistema su cui è installato Unified Manager.
* Dovresti avere la password per l'utente root di MySQL.
* Dovresti essere in grado di accedere allo script fornito da NetApp `password.bat` nella directory
+
`C:\Program Files\NetApp\essentials\bin`.



.Passaggi
. Accedi come utente amministratore al computer host di Unified Manager.
. Usa la console Servizi di Windows per arrestare i seguenti servizi di Unified Manager:
+
** NetApp Active IQ Acquisition Service (Ocie-au)
** NetApp Active IQ servizio del server di gestione (Oncommandsvc)


. Avvia lo `password.bat` script per iniziare la procedura di cambio password:
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. Quando richiesto, inserisci la password dell'utente root di MySQL.
. Quando richiesto, inserisci la nuova password dell'utente JBoss e poi inseriscila nuovamente per conferma.
+
Tieni presente che la password deve essere compresa tra 8 e 16 caratteri e deve contenere almeno una cifra, una lettera maiuscola e una minuscola, e almeno uno di questi caratteri speciali:

+
`+!@%^*-_+=[]:<>.?/~+`

. Al termine dell'esecuzione dello script, avvia i servizi di Unified Manager tramite la console Servizi di Windows:
+
** NetApp Active IQ servizio del server di gestione (Oncommandsvc)
** NetApp Active IQ Acquisition Service (Ocie-au)


. Dopo aver avviato tutti i servizi, puoi accedere all'interfaccia utente di Unified Manager.
