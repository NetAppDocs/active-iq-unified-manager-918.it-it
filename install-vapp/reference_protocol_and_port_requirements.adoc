:allow-uri-read: 
:icons: font
:imagesdir: ../media/

Le porte e i protocolli richiesti consentono la comunicazione tra il server Unified Manager e i sistemi di storage gestiti, i server e gli altri componenti.



[[connections-to-the-unified-manager-server]]
== Connessioni al server Unified Manager

Nelle installazioni tipiche non devi specificare i numeri di porta quando ti connetti all'interfaccia utente web di Unified Manager, perché vengono sempre utilizzate le porte predefinite. Ad esempio, poiché Unified Manager tenta sempre di essere eseguito sulla porta predefinita, puoi inserire `+https://<host>+` invece di `+https://<host>:443+`.

Il server Unified Manager utilizza protocolli specifici per accedere alle seguenti interfacce:

[cols="4*"]
|===
| Interfaccia | Protocollo | Porta | Descrizione 


 a| 
interfaccia utente web di Unified Manager
 a| 
HTTP
 a| 
80
 a| 
Utilizzato per accedere all'interfaccia utente web di Unified Manager; reindirizza automaticamente alla porta sicura 443.



 a| 
Interfaccia utente web di Unified Manager e programmi che utilizzano API
 a| 
HTTPS
 a| 
443
 a| 
Utilizzato per accedere in modo sicuro all'interfaccia utente web di Unified Manager o per effettuare chiamate API; le chiamate API possono essere effettuate solo tramite HTTPS.



 a| 
Console di manutenzione
 a| 
SSH/SFTP
 a| 
22
 a| 
Utilizzato per accedere alla console di manutenzione e recuperare i pacchetti di supporto.



 a| 
riga di comando di Linux
 a| 
SSH/SFTP
 a| 
22
 a| 
Utilizzato per accedere alla riga di comando di Red Hat Enterprise Linux e recuperare i pacchetti di supporto.



 a| 
syslog
 a| 
UDP
 a| 
514
 a| 
Utilizzato per accedere ai messaggi EMS in abbonamento dai sistemi ONTAP e per creare eventi basati su tali messaggi.



 a|

 a| 
HTTPS
 a| 
9443
 a| 
Utilizzato per accedere in tempo reale agli eventi EMS basati su API REST dei sistemi ONTAP autenticati.



 a| 
database MySQL
 a| 
MySQL
 a| 
3306
 a| 
Utilizzato per consentire a OnCommand Workflow Automation e OnCommand API Services di accedere a Unified Manager.



 a| 
Broker AMQP QPID
 a|

 a| 
Utilizzato per la comunicazione dei messaggi interni.



 a| 
Broker AMQP QPID
 a|

 a|

 a|

 a| 
Broker AMQP QPID
 a| 
WebSocket tramite TCP
 a|

Utilizzata per rimanere in ascolto su questa porta per i messaggi ricevuti da ONTAP (cloud agent). La comunicazione su questa porta supporta la crittografia tramite TLS o SSL.

|===
[NOTE]
====
La porta predefinita di MySQL, 3306, è limitata solo a localhost durante l'installazione di Unified Manager sui sistemi VMware vSphere. Ciò non influisce su alcuno scenario di aggiornamento, in cui viene mantenuta la configurazione precedente. Questa configurazione può essere modificata e la connessione può essere resa disponibile ad altri host utilizzando l'opzione  `Control access to MySQL port 3306` nella console di manutenzione. Per informazioni, vedi link:../config/reference_additional_menu_options.html["Opzioni di menu aggiuntive"]. Le porte utilizzate per la comunicazione HTTP e HTTPS (porte 80 e 443) possono essere modificate utilizzando la console di manutenzione di Unified Manager. Per ulteriori informazioni, vedi link:../config/concept_maintenance_console_menu.html["Menu della console di manutenzione"].

====


[[connections-from-the-unified-manager-server]]
== Connessioni dal server Unified Manager

Dovresti configurare il firewall per aprire le porte che consentono la comunicazione tra il server Unified Manager e i sistemi di storage gestiti, i server e gli altri componenti. Se una porta non è aperta, la comunicazione non riesce.

A seconda del tuo ambiente, puoi scegliere di modificare le porte e i protocolli usati dal server Unified Manager per connettersi a destinazioni specifiche.

Il server Unified Manager si connette ai sistemi di storage gestiti, ai server e agli altri componenti utilizzando i seguenti protocolli e porte:

sistema storage

NOTE: Se utilizzi questa porta, o qualsiasi altra porta, per connetterti al VMware vCenter Server o al server ESXi, assicurati che la porta sia disponibile e che sia possibile connettersi in un sito protetto.



 a|
