= Scopri il software VMware e i requisiti di installazione per Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il sistema VMware vSphere su cui installi Unified Manager richiede una versione specifica del sistema operativo e versioni specifiche del software di supporto.



[[operating-system-software]]
== Software del sistema operativo

Il sistema operativo supportato è VMware ESXi 8.0.

[NOTE]
====
Unified Manager OVA su sistemi VMware vSphere esegue internamente il sistema operativo Debian OS 13 (Trixie). Per informazioni sulle versioni dell'hardware delle macchine virtuali che le versioni supportate dei server ESXi possono supportare, consultare la documentazione VMware.

====
Sono supportate le seguenti versioni di vSphere:

* VMware vCenter Server 7.0 e 8.0


Consulta la Interoperability Matrix per l'elenco completo e più aggiornato delle versioni di ESXi supportate.

http://mysupport.netapp.com/matrix["mysupport.netapp.com/matrix"]

L'ora del server VMware ESXi deve essere uguale a quella del server NTP affinché l'appliance virtuale funzioni correttamente. La sincronizzazione dell'ora del server VMware ESXi con quella del server NTP previene errori di temporizzazione.



[[installation-requirements]]
== Requisiti di installazione

VMware High Availability per l'appliance virtuale Unified Manager è supportato.

Se distribuisci un datastore NFS su un sistema storage che esegue il software ONTAP, usa il plug-in NFS di NetApp per VMware VAAI per utilizzare il thick provisioning.

Se la distribuzione non riesce nel tuo ambiente con High Availability abilitata a causa di risorse insufficienti, potresti dover modificare le Cluster Features Virtual Machine Options disabilitando VM Restart Priority e lasciando Host Isolation Response attivo.


NOTE: Durante l'installazione o l'aggiornamento di Unified Manager, il software di terze parti e le patch di sicurezza necessari vengono installati o aggiornati automaticamente su un sistema VMware vSphere. Poiché i processi di installazione e aggiornamento di Unified Manager controllano questi componenti, non devi tentare di installare o aggiornare autonomamente alcun componente di terze parti.
